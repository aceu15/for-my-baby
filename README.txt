# ♡ Birthday Website

This is a self-contained birthday greeting website made with HTML, CSS, and JavaScript.

## How to use it

1. Open the folder in VS Code.
2. Open `index.html`.
3. Put your photos inside the `images` folder.
4. Rename your photos to:
   - `hero.jpg`
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
   - `photo5.jpg`
   - `photo6.jpg`
   - `photo7.jpg`
5. Open `index.html` in your browser.

You can use PNG/WebP photos too, but if you do, change the matching `.jpg` in the HTML to `.png` or `.webp`.

## Most important things to personalize

Search inside `index.html` for these sections:

- `HERO` — change the first message and hero photo.
- `LETTER` — replace the sample birthday letter with your own words.
- `PHOTO GALLERY` — change captions and photos.
- `REASONS` — personalize the three reasons.
- `INTERACTIVE GIFT` — personalize the final hidden message.

## Recommended photo sizes

For the best look:
- Hero: portrait photo, around 1000 × 1250 px.
- Gallery: 800–1600 px on the longest side.
- Keep the photos reasonably compressed so the page loads quickly on mobile.

## Important

Everything is local. There are no external libraries, fonts, images, or APIs required.

The site is designed to work on both desktop and mobile.

If you want to add music later, use a local audio file and a user-controlled play button. Browsers generally block websites from automatically playing audio before the visitor interacts with the page.
